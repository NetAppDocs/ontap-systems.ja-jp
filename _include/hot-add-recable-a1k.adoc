AFF A1K HAペアにシェルフをホットアドする場合、複数のRoCE対応I/Oモジュール間で接続性をバランスさせるために、既存のシェルフの配線をやり直す必要があります。

* 2台目のシェルフをホットアドする場合は、1台目のシェルフをスロット11と10に再配線する必要があります。2台目のシェルフの場合、この手順では、既存のシェルフが各コントローラのスロット11のRoCE対応I/Oモジュールにケーブルで接続されていることを前提としています。
* 4台目のシェルフをホットアドする場合は、3台目のシェルフをスロット9と8に再接続する必要があります。4台目のシェルフの場合、この手順では、3台目のシェルフが各コントローラのスロット9に接続されていることを前提としています。
* 3つ目のシェルフをホットアドし、各コントローラに3つ目または4つ目のRoCE対応I/Oモジュールをインストールする場合、3つ目のシェルフは3つ目のI/Oモジュール、または3つ目と4つ目のI/Oモジュールのみにケーブル接続されます。既存のシェルフの配線をやり直す必要はないので、この手順は省略できます。


.手順
. 2番目のシェルフまたは4番目のシェルフをホットアドする場合は、次のいずれかを実行します。
+
** 2台目のシェルフをホットアドする場合は、各コントローラのスロット11とスロット10のRoCE対応I/Oモジュールで最初のシェルフにケーブルを再接続します。
+
... コントローラAで、ケーブルをスロット11ポートb（e11b）からスロット10ポートb（e10b）に移動します。
... コントローラ B についても、同じケーブルの移動を繰り返します


** 4台目のシェルフをホットアドする場合は、各コントローラのスロット9とスロット8のRoCE対応I/Oモジュールで3台目のシェルフにケーブルを再接続します。
+
... コントローラAで、ケーブルをスロット9のポートb（e9b）からスロット8のポートb（e8b）に移動します。
... コントローラ B についても、同じケーブルの移動を繰り返します




. 再接続されたシェルフがを使用して正しくケーブル接続されていることを確認します https://mysupport.netapp.com/site/tools/tool-eula/activeiq-configadvisor["Active IQ Config Advisor"^]。
+
ケーブル接続エラーが発生した場合は、表示される対処方法に従ってください。
