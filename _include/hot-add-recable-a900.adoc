A900 HAペアにシェルフをホットアドする場合、複数のRoCE対応I/Oモジュール間で接続性をバランスさせるために、既存のシェルフの配線をやり直す必要があります。

* 2台目のシェルフをホットアドする場合は、1台目のシェルフをスロット2と10に再接続する必要があります。2台目のシェルフの場合、この手順では、既存のシェルフが各コントローラのスロット2にあるRoCE対応I/Oモジュールにケーブルで接続されていることを前提としています。
* 4台目のシェルフをホットアドする場合は、3台目のシェルフをスロット1と11に再接続する必要があります。4台目のシェルフの場合、この手順では3台目のシェルフが各コントローラのスロット1に接続されていることを前提としています。


.手順
. 2番目のシェルフまたは4番目のシェルフをホットアドする場合は、次のいずれかを実行します。
+
** 2台目のシェルフをホットアドする場合は、各コントローラのスロット2とスロット10のRoCE対応I/Oモジュールで最初のシェルフにケーブルを再接続します。
+
... コントローラAで、ケーブルをスロット2のポートb（e2b）からスロット10のポートb（e10b）に移動します。
... コントローラ B についても、同じケーブルの移動を繰り返します


** 4台目のシェルフをホットアドする場合は、各コントローラのスロット1とスロット11のRoCE対応I/Oモジュールで3台目のシェルフにケーブルを再接続します。
+
... コントローラAで、ケーブルをスロット1のポートb（e1b）からスロット11のポートb（e11b）に移動します。
... コントローラ B についても、同じケーブルの移動を繰り返します




. 再接続されたシェルフがを使用して正しくケーブル接続されていることを確認します https://mysupport.netapp.com/site/tools/tool-eula/activeiq-configadvisor["Active IQ Config Advisor"^]。
+
ケーブル接続エラーが発生した場合は、表示される対処方法に従ってください。
