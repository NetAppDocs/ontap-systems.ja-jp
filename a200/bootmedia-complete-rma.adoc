= 障害が発生した AFF A200 ブートメディアを NetApp に返却する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ブートメディアの交換後、キットに同梱されているRMAの手順書に記載されているとおり、障害が発生した AFF A200 のブートメディアを NetApp に返却してください。詳細については、 https://mysupport.netapp.com/site/info/rma["パーツの返品と交換"]ページを参照してください。
