= AFF A700システムでシャーシを交換するための要件を確認する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFF A700システムのシャーシを交換する前に、円滑な交換のための要件を確認してください。シャーシ交換手順では、障害のあるシャーシから交換用シャーシへすべてのコンポーネントを移動するため、システムの停止を伴います。

システムのその他のコンポーネントがすべて正常に動作している必要があります。問題がある場合は、必ずテクニカルサポートにお問い合わせください。

* この手順は、システムでサポートされるすべてのバージョンの ONTAP で使用できます。
* この手順はシステムの停止を伴います。2 ノードクラスタではサービスが完全に停止し、マルチノードクラスタでは部分的に停止します。
