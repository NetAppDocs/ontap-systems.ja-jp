= AFF A700s シャーシを交換する前に要件を確認してください
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFF A700s システムのシャーシを交換する前に、円滑な交換のための要件を確認してください。シャーシ交換手順では、コントローラーモジュールと SSD ドライブを障害のあるシャーシから交換用シャーシに移設するため、システムの停止を伴います。

システムのその他のコンポーネントがすべて正常に動作している必要があります。問題がある場合は、必ずテクニカルサポートにお問い合わせください。

* この手順は、システムでサポートされるすべてのバージョンの ONTAP で使用できます。
* この手順は、 SSD とコントローラモジュールをネットアップ製の新しいシャーシに移動することを前提としています。
* この手順はシステムの停止を伴います。2 ノードクラスタではサービスが完全に停止し、マルチノードクラスタでは部分的に停止します。
