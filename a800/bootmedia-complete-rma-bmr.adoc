= 障害が発生した AFF A800 ブートメディアを自動ブートリカバリプロセス後に NetApp に返却する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFF A800システムで障害が発生したブートメディアの自動ブート回復プロセスが完了したら、障害が発生した部品をNetAppに返送してください。詳細については、 https://mysupport.netapp.com/site/info/rma["パーツの返品と交換"]ページを参照してください。
