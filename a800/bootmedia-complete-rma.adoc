= 障害が発生した AFF A800 ブートメディアを手動ブートリカバリプロセス後に NetApp に返却する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFF A800システムで障害が発生したブートメディアの手動ブートリカバリプロセスを完了したら、障害が発生した部品をNetAppに返却してください。詳細については、 https://mysupport.netapp.com/site/info/rma["パーツの返品と交換"]ページを参照してください。
