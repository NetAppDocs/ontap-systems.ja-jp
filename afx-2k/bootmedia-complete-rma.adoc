= 自動ブートリカバリプロセスの完了後、障害が発生したAFX 2KブートメディアをNetAppに返送してください
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFX 2Kストレージシステムのコンポーネントが故障した場合は、故障した部品を NetApp に返送してください。詳細については、 https://mysupport.netapp.com/site/info/rma["パーツの返品と交換"]ページをご覧ください。
