= 障害が発生した AFF C250 ブートメディアを自動ブートリカバリプロセス後に NetApp に返却する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AFF C250 システムのブートメディアを交換したら、キットに同梱されている RMA 指示書に従って、障害が発生した部品を NetApp に返送してください。詳細については、 https://mysupport.netapp.com/site/info/rma["パーツの返品と交換"]ページを参照してください。
