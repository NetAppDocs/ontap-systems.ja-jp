= AFF C250ストレージシステムをクイック手順でインストールする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
グラフィック クイック ステップ ポスターを使用して、ラックへの設置やケーブル接続から初期システムの立ち上げまで、AFF C250ストレージ システムを設置します。この形式は、NetAppシステムの設置にすでに慣れている場合に最適です。
