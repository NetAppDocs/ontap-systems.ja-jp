= FAS2600システムにおけるシャーシ交換の要件を確認する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS2600システムのシャーシを交換する前に、電源装置、ハードドライブ、コントローラモジュールを故障したシャーシから新しいシャーシに移動するための要件、および機器ラックまたはシステムキャビネット内の故障したシャーシを同じモデルの新しいシャーシと交換するための要件を確認してください。

システム内の他のすべての構成要素も正常に機能していなければなりません。そうでない場合は、テクニカルサポートにお問い合わせください。

* この手順は、システムでサポートされるすべてのバージョンの ONTAP で使用できます。
* この手順は、すべてのドライブとコントローラモジュールをネットアップ製の新しいシャーシに移動することを前提としています。
* この手順はサービスを停止させます。2ノードクラスタの場合は完全なサービス停止が発生し、マルチノードクラスタの場合は部分的なサービス停止が発生します。
