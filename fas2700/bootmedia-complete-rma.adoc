= 障害が発生したFAS2700ブートメディアをNetAppに返送してください
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS2700システムのブートメディアを交換したら、キットに同梱されているRMA手順書に記載されているとおりに、障害が発生した部品をNetAppに返送してください。

詳細については、 https://mysupport.netapp.com/site/info/rma["パーツの返品と交換"]ページを参照してください。FAS2700システムは、手動によるブートメディアリカバリ手順のみをサポートしています。自動ブートメディア復旧はサポートされていません。
