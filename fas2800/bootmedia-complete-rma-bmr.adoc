= 障害が発生した FAS2820 ブートメディアを自動ブートリカバリプロセス後に NetApp に返却する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS2820システムのコンポーネントに障害が発生した場合は、障害が発生した部品をNetAppに返却してください。詳細については、 https://mysupport.netapp.com/site/info/rma["パーツの返品と交換"]ページを参照してください。
