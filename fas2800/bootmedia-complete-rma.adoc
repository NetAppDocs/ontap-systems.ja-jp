= 障害が発生した FAS2820 ブートメディアを、手動ブートリカバリプロセスの完了後に NetApp に返却してください
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS2820システムのブートメディアを交換したら、キットに同梱されているRMA手順書に記載されているとおりに、障害のある部品をNetAppに返送してください。

障害が発生したパーツは、キットに付属のRMA指示書に従ってNetAppに返却してください。 https://mysupport.netapp.com/site/info/rma["パーツの返品と交換"]詳細については、ページを参照してください。
