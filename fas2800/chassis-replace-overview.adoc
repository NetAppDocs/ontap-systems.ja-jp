= FAS2820システムのシャーシを交換する前に要件を確認してください
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS2820システムのシャーシを交換するには、電源装置、ハードドライブ、およびコントローラモジュールを、故障したシャーシから新しいシャーシに移設します。次に、故障したシャーシを機器ラックまたはシステムキャビネットから取り外し、同じモデルの新しいシャーシをその場所に取り付けます。

システム内の他のすべての構成要素も正常に機能していなければなりません。そうでない場合は、テクニカルサポートにお問い合わせください。

* この手順は、システムでサポートされるすべてのバージョンの ONTAP で使用できます。
* この手順は、すべてのドライブとコントローラモジュールをネットアップ製の新しいシャーシに移動することを前提としています。
* この手順はサービスを停止させます。2つのコントローラーで構成されるクラスタの場合、この手順を実行するとサービスが完全に停止し、複数ノードで構成されるクラスタの場合は部分的なサービス停止が発生します。
