= FAS8200システムのシャーシ交換の要件を確認します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS8200システムのシャーシを交換する前に、他のすべてのコンポーネントが正しく機能していること、および交換用シャーシが同じモデルのNetAppの新しいコンポーネントであることを確認してください。この手順では、電源装置、ファン、およびコントローラモジュールを新しいシャーシに移設する必要があり、システムへの影響が大きいため、2つのコントローラで構成されるクラスタでは完全なサービス停止、複数ノードのクラスタでは部分的なサービス停止が発生します。

システム内の他のすべての構成要素も正常に機能していなければなりません。そうでない場合は、テクニカルサポートにお問い合わせください。

* この手順は、システムでサポートされるすべてのバージョンの ONTAP で使用できます。
* この手順は、コントローラモジュールをネットアップ製の新しいシャーシに移動することを前提としています。
* この手順はシステムの停止を伴います。2つのコントローラーで構成されるクラスタでは、サービスが完全に停止し、マルチノードクラスタでは部分的なサービス停止が発生します。
