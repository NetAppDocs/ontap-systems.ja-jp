= FAS9000 システムのシャーシ交換の要件を確認します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS9000 システムのシャーシを交換する前に、他のすべてのコンポーネントが正常に機能していること、および交換用シャーシが障害のあるシャーシと同じモデルであることを確認してください。この手順は停止を伴い、2ノードクラスタでは完全なサービス停止、マルチノードクラスタでは部分的なサービス停止が発生します。

システムのその他のコンポーネントがすべて正常に動作している必要があります。問題がある場合は、必ずテクニカルサポートにお問い合わせください。

* この手順は、システムでサポートされるすべてのバージョンの ONTAP で使用できます。
* この手順はシステムの停止を伴います。2 ノードクラスタではサービスが完全に停止し、マルチノードクラスタでは部分的に停止します。
