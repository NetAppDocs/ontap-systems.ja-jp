= X91148AモジュールをFAS9000システムに追加する方法について
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
X91148AモジュールをFAS9000システムに追加するには、既に部品が実装されているシステムでNICまたはストレージアダプタを新しいものと交換するか、空いているシャーシスロットに新しいNICまたはストレージアダプタを追加します。

システムに I/O モジュールを追加するには、 NIC またはストレージアダプタをフル搭載システムの新しいアダプタに交換するか、新しい NIC またはストレージアダプタをシステムの空のシャーシスロットに追加します。

.作業を開始する前に
*  https://hwu.netapp.com["NetApp Hardware Universe の略"]を確認して、新しいI/Oモジュールがシステムおよびお客様が実行しているONTAPのバージョンと互換性があることを確認してください。
* 複数のスロットが使用可能な場合は、 https://hwu.netapp.com["NetApp Hardware Universe の略"]のスロット優先順位を確認し、I/Oモジュールに最適なスロットを使用してください。
* 無停止で I/O モジュールを追加するには、ターゲットコントローラをテイクオーバーし、ターゲットスロットのスロットブランクカバーを取り外すか、既存の I/O モジュールを取り外し、新しい I/O モジュールまたは交換用 I/O モジュールを追加して、ターゲットコントローラをギブバックする必要があります。
* 他のすべてのコンポーネントが正常に機能していることを確認します。
