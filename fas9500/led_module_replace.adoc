= FAS9500 システムの LED USB モジュールをホットスワップする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FAS9500 システムの LED USB モジュールは、コンソールポートへの接続とシステムステータスを提供します。交換には工具は不要で、サービスも中断されません。



[[step-1-replace-the-led-usb-module]]
== 手順 1 ： LED USB モジュールを交換します

.手順
. 古い LED USB モジュールを取り外します。
+
.アニメーション- LED - USBモジュールの取り外し/取り付け
video::bc46a3e8-6541-444e-973b-ae78004bf153[panopto]
+
image::../media/drw_9500_remove_replace_LED_mod.svg[LEDモジュールを交換する]

+
[cols="20%,80%"]
|===


 a| 
image::../media/icon_round_1.png[番号1]
 a| 
ロックボタン



 a| 
image::../media/icon_round_2.png[番号2]
 a| 
USB LED モジュール

|===
+
.. ベゼルを取り外した状態で、シャーシ前面の左下にある LED USB モジュールの位置を確認します。
.. ラッチをスライドさせて、モジュールの一部をイジェクトします。
.. モジュールをベイから引き出し、ミッドプレーンから取り外します。スロットを空のままにしないでください。


. 新しい LED USB モジュールを取り付けます。
+
.. モジュールの角にある切り欠きがシャーシのスライダーラッチ付近に来るように、モジュールをベイに位置合わせしてください。このベイのおかげで、モジュールを上下逆さまに取り付けることができません。
.. モジュールをベイに押し込んで、完全にシャーシと同一面になるようにします。
+
モジュールがしっかりと固定され、ミッドプレーンに接続されると、カチッという音が鳴ります。







[[step-2-return-the-failed-component]]
== 手順 2 ：障害が発生したコンポーネントを返却する

. 障害が発生したパーツは、キットに付属のRMA指示書に従ってNetAppに返却してください。 https://mysupport.netapp.com/site/info/rma["パーツの返品と交換"^]詳細については、ページを参照してください。
