[role="lead"]
NS224シェルフをASAシステムにケーブル接続して、HAペアのストレージ冗長性と高可用性を確保するデュアルパス接続を提供します。



[[cabling-overview-for-asa-systems]]
== ASAシステムのケーブル配線の概要

ASAプラットフォームモデルによってケーブル接続が異なります。各システムには固有のポート割り当てとI/Oモジュール構成があるためです。

ホットアド ケーブル接続手順では、各NS224シェルフをHAペアの両方のコントローラに接続します。

* 各シェルフの NSM モジュールは、各コントローラの専用ストレージポートに接続され、シェルフごとに 2 つのパス（ NSM A 経由と NSM B 経由）が作成されます。
* この二重経路構成により、ストレージの冗長性が確保され、単一の経路が故障した場合でもデータへのアクセスが継続されます。
* ケーブルは、シェルフNSMのe0a/e0bポート（NSM100）またはe1a/e1bポート（NSM100B）から、コントローラ上のRoCE対応ストレージポートに接続されます。
