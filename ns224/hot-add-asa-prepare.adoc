= NS224シェルフをASAシステムにホットアドするための準備の概要
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
十分な数の RoCE 対応ストレージポートを確保し、それらをストレージ用途に設定し、既存の構成を新しいシェルフに合わせて最適化することで、NS224 シェルフを ASA システムにホットアドする準備をしてください。



[[what-to-prepare]]
== 準備するもの

ASAシステムにNS224シェルフをホットアドする準備には、新しいシェルフを物理的に設置する前に、ストレージ接続インフラストラクチャの検証と構成が含まれます。これらの作業により、HAペアに必要なRoCE対応イーサネットポートが備わっていること、およびシステムが追加のストレージ容量をサポートするように構成されていることが保証されます。

必要な準備作業は、プラットフォームのモデル、現在の構成、および追加するシェルフの数によって異なります。

RoCE対応PCIeカードまたはI/Oモジュールの取り付け:: システムに十分な数のRoCE対応イーサネットポート（各コントローラのシェルフごとに2つ）が利用可能であることを確認してください。追加のポートが必要な場合は、RoCE対応のPCIeカードまたはI/Oモジュールを適切なコントローラスロットに取り付けてください。
ストレージ用のRoCE対応ポートの設定:: NS224シェルフを接続するために専用ではないRoCE対応ポートを使用する場合は、それらのポートをネットワーク用ではなくストレージ用として構成してください。これは無停止の手順です。
既存のシェルフを再接続:: プラットフォームモデルによっては、RoCE対応PCIeカードまたはI/Oモジュールを追加でインストールした後、スロット障害に対する耐障害性を確保するために、異なるスロットにある2組のポートにわたって既存のシェルフを再配線する必要がある場合があります。
自動ドライブ割り当ての無効化:: ドライブの所有権を手動で割り当てる予定がある場合は、シェルフをホットアドする前に、ドライブの自動割り当てを無効にしてください。
